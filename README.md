# shatter-kingdoms-privacy-policy

Public legal and support pages for the **Shatter Kingdoms** iOS game, served with GitHub Pages.

| Page | URL (after enabling Pages) |
|---|---|
| Home | https://umit-turk.github.io/shatter-kingdoms-privacy-policy/ |
| Privacy Policy (EN) | https://umit-turk.github.io/shatter-kingdoms-privacy-policy/privacy-policy.html |
| Gizlilik Politikası (TR) | https://umit-turk.github.io/shatter-kingdoms-privacy-policy/privacy-policy-tr.html |
| Terms of Use | https://umit-turk.github.io/shatter-kingdoms-privacy-policy/terms.html |
| Support | https://umit-turk.github.io/shatter-kingdoms-privacy-policy/support.html |

The game links to the Privacy Policy, Terms and Support pages from **Settings → Help & Legal**, and the same Privacy
Policy and Support URLs go into App Store Connect.

## Publishing
Repository **Settings → Pages → Build and deployment**: Source *Deploy from a branch*, Branch `main`, folder `/ (root)`.

## Keeping it accurate
Update the pages and their effective date whenever the game's data practices change (for example new SDKs, analytics,
accounts or cloud saves). The current policy reflects: no data collected by the developer, progress stored on device,
purchases processed by Apple, and ads served by Google AdMob with UMP consent and App Tracking Transparency (not started
for Remove Ads owners).
